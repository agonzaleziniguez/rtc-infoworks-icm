# rtc-infoworks-icm-mcp

An MCP server under development to help an AI assistant translate your
real-time control objectives into library-generated RTC files and Python scripts.

**Not usable yet:** the command is a placeholder, not a working MCP server.

See the [project's MCP overview](https://github.com/agonzaleziniguez/rtc-infoworks-icm#mcp-server-in-development)
for the intended experience and limitations.
